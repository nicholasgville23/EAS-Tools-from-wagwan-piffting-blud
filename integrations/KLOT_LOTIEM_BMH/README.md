# KLOT LOTIEM EAS + BMH Laboratory Integration

This integration is simulation-only. It adds the requested KLOT LOTIEM Text Workstation/BMH/EAS data model to the EAS Tools repository. It does not transmit EAS/SAME tones, RF, NWR audio, or public emergency alerts. The full Tkinter prototype is supplied as a downloadable ZIP with this response.

Run the full package with `py -3 app.py`; build a Windows executable with `build_windows.bat` after installing PyInstaller.
